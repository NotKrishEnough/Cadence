# Cadence

Cadence is an original Jetpack Compose music-player project inspired by the clean, library-first experience of modern Android music players.

## Stack
- Kotlin
- Jetpack Compose / Material 3
- AndroidX Media3
- Coil
- Navigation Compose

## Branch
The `accord-compose` branch contains the current Compose rebuild.

## Build
Open the project in Android Studio and run the `app` configuration, or run:

```bash
./gradlew assembleDebug
```

The GitHub Actions workflow also builds the debug APK on pushes and pull requests to `accord-compose`.
